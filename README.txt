INSTALLATION AND DEPLOYMENT

1. Upload all application files to the root of the GitHub repository.
2. Commit the files to the main branch.
3. Open repository Settings.
4. Select Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select main as the branch.
7. Select /(root) as the folder.
8. Tap Save.
9. Wait for GitHub Pages to publish the website.
10. Open the published website using Chrome.

FEATURES

- Online English dictionary lookup.
- Definitions and parts of speech.
- Phonetic spelling and audio pronunciation when available.
- Synonyms and example sentences when available.
- Favourite words and recent searches.
- Offline starter vocabulary.
- Previously searched words stored on the device.
- Installable web application.

OFFLINE INFORMATION

Open the application online at least once before using it offline.
The application files and starter vocabulary are cached.
Words searched successfully online are stored on that device.
A full English dictionary is not downloaded for offline use.

This project is a Progressive Web App (PWA), not an Android APK.

## Important before you start

- Create each file using its exact filename.
- Paste the complete code into the editor.
- Commit each file to the `main` branch.
- If a file already exists, edit that file instead of creating a duplicate.
- The online dictionary uses a public dictionary API. It can look up many English words, but results depend on the API and internet connection.
- Offline search is limited to the starter vocabulary and words previously searched on that device.
